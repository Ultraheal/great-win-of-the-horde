# Раскирпичивание роутера (оно же откат на прошивку Xiaomi)
Инструкция взята из следующих источников:
- https://habr.com/ru/articles/820417/
- https://4pda.to/forum/index.php?showtopic=1033757&st=360#entry114089118
- https://forum.openwrt.org/t/xiaomi-mi-router-4a-gigabit-edition-r4ag-r4a-gigabit-fully-supported-and-flashable-with-openwrtinvasion/36685/747?u=mikeeq

Порядок раскирпичивания/отката на родную прошивку:
1. Скачиваем из официального источника [Xiaomi Recovery Tool](http://bigota.miwifi.com/xiaoqiang/tools/MIWIFIRepairTool.x86.zip), либо берем в этом репозитории.
2. Скачиваем прошивку для роутера из официального источника [1.0.83](http://cdn.awsde0-fusion.fds.api.mi-img.com/xiaoqiang/rom/rb01/miwifi_rb01_firmware_d8243_1.0.83_INT.bin), либо берем в этом репозитории.
3. В параметрах сетевого интерфейса ставим значения IP-адреса 192.168.31.100 и маску подсети 255.255.255.0:
   (Пуск - Параметры - Сеть и Интернет - Ethernet - Назначение IP - Вручную - IPv4 включить - указать IP-адрес 192.168.31.100 и шлюз 255.255.255.0 - Сохранить). В поле выбираем подключение "Ethernet -> 192.168.31.100"
4. Распаковываем и запускаем MIWIFIRepairTool.x86.exe
5. В Xiaomi Recovery Tool нажимаем на кнопку "??" и выбираем файл прошивки. Далее нажимаем "???" внизу справа.
6. Оказываемся тут - <img width="500" height="358" alt="image" src="https://github.com/user-attachments/assets/c863d863-e1a6-4d2d-924f-3d5572444f2f" />
7. Выключаем роутер
8. Удерживая кнопку Reset на задней стороне роутера, включаем роутер. После ~10 секунд ожидания желтый светодиод System должен начать мигать, отпускаем кнопку Reset.
9. Далее появится мелкое окно загрузки прошивки, после окончания загрузки светодиод System должен мигать синим цветом.
10. Сбрасываем настройки сетевого интерфейса обратно
11. Закрываем Xiaomi Recovery Tool, заходим на 192.168.31.1 (если не заходит - выключаем и включаем роутер).
